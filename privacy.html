Política de Privacidade do GrantLens

Última atualização: 17 de outubro de 2026.

1. Quem somos

GrantLens é um aplicativo de desktop desenvolvido por Vinícius Rocha de Morais. Contato: itapevatigercats@gmail.com.

2. Dados que o aplicativo acessa

  • Arquivos locais: lê os arquivos da pasta que você abrir, no seu computador. Eles não são enviados a nós.
  • Google Drive (opcional): se você entrar com sua conta Google, o aplicativo pede o acesso drive.file, que permite ler somente os arquivos que você selecionar na janela de seleção do Google. O aplicativo não lista nem lê os demais arquivos do seu Drive.
  • Informações da conta: o aplicativo recebe do Google apenas um token de acesso para esses arquivos. Não coletamos seu nome, e-mail ou contatos.

3. Como usamos os dados do Google

Os arquivos selecionados são exportados como .docx/.xlsx e gravados na pasta .grantlens/cloud do projeto, no seu computador, para que o aplicativo possa lê-los. Não usamos esses dados para publicidade, não os vendemos e não os transferimos a terceiros. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

4. Onde ficam os dados

Tudo é armazenado localmente. O token de acesso do Google é guardado no seu computador, criptografado pelo sistema operacional. Nós não operamos servidores que recebam seus arquivos ou tokens.

5. Assistente de IA (opcional)

Se você informar uma chave de API da Anthropic, trechos de documentos que você pedir ao assistente para analisar são enviados diretamente do seu computador à Anthropic, conforme a política de privacidade dela. Isso não acontece sem a sua chave. Dados bancários podem ser mascarados antes do envio.

6. Retenção e exclusão

Você controla os dados: apague a pasta .grantlens do projeto para remover os arquivos exportados e o inventário. Para revogar o acesso ao Google, desconecte no aplicativo e remova o GrantLens em myaccount.google.com/permissions.

7. Crianças

O aplicativo não se destina a menores de 13 anos.

8. Alterações

Podemos atualizar esta política; a data no topo indica a versão vigente.

9. Contato

itapevatigercats@gmail.com

Privacy Policy (summary in English)

GrantLens is a desktop app. It reads files from the folder you open on your computer. If you sign in with Google, it requests the drive.file scope and can read only the files you select in Google's file picker, exporting them as .docx/.xlsx into your local project folder. We operate no servers: your files and tokens stay on your device (tokens are encrypted by your operating system). We do not sell or share Google user data and do not use it for advertising. GrantLens's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. If you provide your own Anthropic API key, text you ask the assistant to analyze is sent from your computer directly to Anthropic. Revoke access at any time at myaccount.google.com/permissions. Contact: itapevatigercats@gmail.com.
